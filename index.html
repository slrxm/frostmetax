ID матча
Введите ID матча из клиента Dota 2 или с сайта Dotabuff / OpenDota.

Подойдёт числовой Steam ID (32 или 64 бита), ссылка Dotabuff / OpenDota / Steam или ник. Профиль должен открывать историю матчей.

Статистика считается по всей публичной истории матчей. Если вводите ник, берётся лучшее совпадение: для точности используйте числовой ID.
