# Повторная проверка и реорганизация

HTML теперь содержит разметку и ссылки на файлы. Оригинальная логика меты, матчей,
игроков, графиков и сравнения вынесена в src/core.js, тема — в src/theme.css.
Классический script сохранён намеренно: существующие обработчики и модульные карточки
используют его публичные функции. Это сохраняет обратную совместимость без переписывания
всех обработчиков одновременно. Сборка копирует исходники в core.js/theme.css и dist/.
Править нужно src/, затем выполнять npm run build.

Карточки используют отдельный JSON-клиент с кешем, объединением одновременных запросов,
таймаутом и повторной возможностью запроса после ошибки. Исходные API-запросы также
ограничены таймаутом. Поиск матча защищён от устаревших ответов. Dota ID проверяется
по диапазону; ссылки принимаются только с поддерживаемых доменов.

Сохранены: фильтры меты, поиск/сортировка, карточки героев, предметы и соперники, загрузка
матчей, запрос разбора, графики и события, игроки и история, сравнение, локальный профиль,
скачивание и оба мобильных проекта. Версия кеша обновлена для новых файлов.

Локально: 13 JavaScript-тестов, 5 Python-тестов и 7 браузерных сценариев.
Покрытие дополнено просмотром игрока, сравнением, матчем с графиком и кратким разбором,
проверкой идентификаторов и кеша запросов. Эти проверки не заменяют тестирование
на физических Android/iOS-устройствах и не гарантируют доступность внешних API.
