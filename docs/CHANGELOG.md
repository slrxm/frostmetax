# Подготовленные изменения

- Новая сгенерированная иконка F, версии сайта, Android adaptive icon, iOS icon и splash screens.
- Сброс старого кеша FROSTMETA, обновление service worker и версии URL иконок.
- Кнопка скачивания с настраиваемыми реальными ссылками на магазины/APK.
- Google OAuth + PKCE на сервере, Steam OpenID с проверкой подписанных полей,
  проверкой на стороне Steam, ограничением времени, одноразовым состоянием и защитой от replay.
- SQLite аккаунты, хеши сессий, привязка Steam/Dota, отвязка, выход, удаление аккаунта.
- Системный браузер для мобильного входа и одноразовый обмен результата по отдельному секрету.
- Проекты Capacitor Android и iOS; workflow для тестов и Android debug APK.
- Переход недельного запроса STRATZ на суточный, расписание раз в три часа,
  сохранение данных при ошибках, отдельные отметки проверки и изменения, status-файл.
- Автопроверка меты в интерфейсе, ручное обновление, состояние потери сети и пустого фильтра.
- Исправлена ширина полосы винрейта ниже 44%.

Не подключены: production-сервер/домен, Google OAuth credentials, Apple/Google магазины,
Sign in with Apple. Реальный вход и новый STRATZ запрос требуют проверки после подключения.
