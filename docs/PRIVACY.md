# Политика обработки данных — черновик для владельца

Перед публикацией владелец должен указать своё имя/организацию, контакт для обращений,
регион размещения сервера, сроки хранения и применимые правовые основания.
Этот файл — техническое описание реализации, не готовая юридическая политика.

Сохраняются: имя и подтверждённая почта Google, внутренний Google subject, Steam ID,
Dota account ID и хеши сессий. Пароли и access tokens Google не сохраняются в БД.
Сессии истекают через 30 дней; незавершённые входы через 10 минут.
В мобильной версии токен остаётся в памяти до завершения процесса.
Статистика OpenDota отображается по публичному профилю; привязка не открывает закрытую историю.

В разделе аккаунта есть отвязка Steam, выход и удаление аккаунта. Удаление стирает
пользователя, сессии и ожидающие привязки из рабочей базы. Владелец определяет сроки
удаления из резервных копий и эксплуатационных логов.

Внешние сервисы: Google (вход), Steam (подтверждение профиля), OpenDota (матчи),
STRATZ (мета), GitHub Pages (доставка статистики), Steam CDN (изображения).
Подготовить опубликованную политику и заполнить сведения магазинов перед релизом.
