# Бесплатная аналитика героев

В текущем интерфейсе сервер и Google/Steam-авторизация не используются. Вместо них Dota ID
или числовая ссылка Steam сохраняется в localStorage устройства. Это закладка на профиль,
а не подтверждение владения. Можно удалить ID; синхронизации между устройствами нет.
Старый backend остаётся в исходниках как необязательная заготовка и на Pages не запускается.

Нажатие на имя героя в таблице открывает карточку:
- STRATZ: винрейт, пикрейт, объём выборки для текущего рейтинга и позиции;
- OpenDota: сложные и удобные соперники с винрейтом и числом игр, минимум 30 матчей;
- предметы по стадиям игры: число покупок, а не процент побед с предметом;
- недавние профессиональные матчи на герое с переходом в разбор.

Выборки не смешиваются: фильтры рейтинга/позиции STRATZ не применяются к OpenDota.
Соперники: профессиональные матчи за последний год, без фильтра текущего патча.
Поэтому это ориентир, а не текущие контрпики для конкретного ранга или причинный эффект пика.
Предметы: до 100 последних разобранных профессиональных матчей; популярные предметы
не складываются автоматически в готовый билд. Предметы конкретного матча и время их
покупки доступны в разборе, если OpenDota обработал replay.

Краткий разбор матча вычисляет лидера GPM, наибольшее поминутное изменение преимущества
и отыгрыш дефицита более 5000 золота. Он не объясняет причины победы и не оценивает игрока.
При отсутствии поминутных данных отображается подсказка о запросе обработки матча.

Ответы OpenDota кешируются на 10 минут в памяти. Запросы выполняются при открытии карточки,
список матчей — по отдельной кнопке. Ошибка одного раздела не скрывает остальные.
Бесплатный API может ограничивать частоту запросов. Данные Dotabuff не скопированы.
